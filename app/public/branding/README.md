# PISG brand asset

The logo is a direct raster crop of the user-provided `PISG-CP-Q32026-R1.pdf`, page 1, rendered with Poppler. It is not a recreated logo. The original supplied image is low-resolution; the PNG preserves its appearance on the cover's charcoal backing.

UI palette references pages 1 and 3: charcoal #232d32, orange #ff681b, white text, lighter orange #ffad7a for readable links on dark surfaces. Supporting blue is retained for the progress chart's current-state point, and semantic error/success colors remain distinct. These are interface adaptations, not a claim of a formally issued brand specification.
