## 驗收期間修正

1. 空 request body 的 POST 原本仍送出 `Content-Type: application/json`，Fastify 會回傳 400。共用 API client 已改為空 body 自動移除該 header，並新增回歸測試。
2. `daily_report_tasks` 與 `daily_report_labor_entries` 原本使用限制刪除外鍵，會阻止專案清理。已改為 `ON DELETE CASCADE` 並套用 Supabase migration。

## 已確認的安全行為

- 未啟用的邀請帳號不可加入專案。
- WBS 版本建立者不可自行核准，核准必須由另一位具權限的 Manager 執行。
- 專案版本已變動時，舊 ETag 的修改或封存會回傳 409，避免覆蓋新資料。
